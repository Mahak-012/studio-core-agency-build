## 🧭 Executive Overview

**Studio Core** is a next-generation, high-performance B2B digital product studio landing page inspired by world-class design benchmarks like Apple and Work & Co. Engineered with meticulous attention to micro-interactions, pitch-black dark-mode aesthetics, custom canvas particle constellations, and an advanced developer-first design architecture.

---

## 🏛️ Architectural Breakdown & Components

```text
src/
├── components/
│   ├── Navbar.jsx            # Sticky high-performance glassmorphism header with mobile drawer
│   ├── Hero.jsx              # Cinematic hero with particle canvas, rotating headings & live terminal
│   ├── CapabilityGrid.jsx    # Responsive 3-column service cards with hover glassmorphism
│   ├── CaseShowcase.jsx      # High-end alternating enterprise platform layouts
│   ├── ContactPanel.jsx      # Minimalist single-line input form for enterprise collaboration
│   └── Footer.jsx            # Clean copyright and brand asset links
├── pages/
│   └── Home.jsx              # Central assembler page wrapping all layout segments
├── App.jsx                   # Global entry mounting the main application pipeline
└── main.jsx                  # DOM root render hub


## ✨ Features

- **Cinematic Dark-Mode Hero:** Immersive particle constellation canvas, dynamic word rotation, live terminal typing indicator, and magnetic CTA buttons.
- **Interactive Capability Grid:** Responsive 3-column service showcase featuring advanced glassmorphism cards and subtle border gradients.
- **Dense Case-Studies Showcase:** High-end alternating layout displaying enterprise platforms and modern tech architectures.
- **Micro-Conversion Contact Panel:** Minimalist, center-aligned input form with clean single-line borders for seamless enterprise engagement.
- **Fully Responsive & Optimized:** Tailored layouts spanning across mobile, tablet, and wide desktop viewports with reduced-motion support.
